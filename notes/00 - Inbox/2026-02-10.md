Good Code:
- Passes the tests: Does what it is supposed to do
- Reveals intention: Code that is understandable
- No duplication: Don't repeat yourself "DRY" - because then we need to make changes in multiple places
- Fewest Number of Elements: Bugs scale linearly with the number of lines of code, so be minimal and simple
